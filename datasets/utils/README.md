# Dataset utilities

| Directory | Responsibility |
|---|---|
| [data_helpers](data_helpers/README.md) | Read inputs, convert/normalize representations and check paired files |
| [data_presenters](data_presenters/README.md) | Colored audio-video flat images and playable MP4 exports |
| [augmentations](augmentations/README.md) | Training transforms; separate image/video/audio modules |
| [perturbations](perturbations/README.md) | Generate offline perturbation versions from standardized data |

Each directory's README describes its members and usage.
